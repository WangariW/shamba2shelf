# 🌍 Shamba2Shelf

Full-stack agri-commerce and storytelling platform designed to support small-scale Kenyan coffee farmers through digital storytelling, product discovery, and marketplace interaction.

---

## 🚀 Overview

Shamba2Shelf is a web-based platform created to bridge the gap between small-scale coffee farmers and consumers by combining storytelling, e-commerce, and logistics into a unified digital experience.

The platform enables farmers to showcase their products, share their stories, manage listings, and connect with buyers through an interactive and scalable marketplace system.

---

## 🧩 Architecture

The system follows a modular full-stack architecture consisting of:
- A React-based frontend for user interaction and marketplace experiences
- RESTful backend APIs built with Node.js and Express.js
- MongoDB for flexible product, order, and user data storage
- Authentication and middleware layers for secure access control
- Geolocation and mapping integrations for farm visualization and logistics support

---

## ✨ Features

- 👨‍🌾 Farmer profile and storytelling system

## ⚙️ Installation & Setup

### Clone the Repository

```bash
git clone https://github.com/WangariW/Shamba2Shelf.git
cd Shamba2Shelf
```

---

## 🌐 Frontend Setup

### Navigate to frontend directory

```bash
cd frontend
```

### Install dependencies

```bash
npm install
```

### Run development server

```bash
npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```

---

## ⚙️ Backend Setup

### Navigate to backend directory

```bash
cd backend
```

### Install dependencies

```bash
npm install
```

### Run backend server

```bash
npm run dev
```
